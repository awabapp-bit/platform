# منصة أواب الإلكترونية — موقع المستخدم

موقع مستقل بالكامل (لا يعتمد على أي ملفات خارج هذا المجلد غير Firebase).

| الملف | الوظيفة |
|---|---|
| `index.html` | تسجيل الدخول (نقطة الدخول) + نسيت كلمة المرور |
| `register.html` | إنشاء حساب |
| `home.html` | الرئيسية: كل الكورسات والمسابقات المتاحة |
| `account.html` | الحساب الشخصي: مستواك، نقاطك، الكورسات/المسابقات المشترك بها |
| `competition.html?id=...` | صفحة المحتوى: صورة + اسم + وصف + محاضرات أكورديون (فيديوهات/اختبارات/مرفقات) |
| `video.html` | فيديو واحد + تعليقات + مشاركة |
| `exam.html` | اختبار واحد (محاولة وحيدة) |
| `forum.html?id=...` | منتدى الأسئلة الخاص بالكورس/المسابقة: سؤال (نص + صورة اختيارية) يرد عليه المسؤول فقط |

## الملفات المطلوبة بجانب الصفحات (كل حاجة في نفس المستوى، مفيش مجلدات فرعية)
```
awab-user-site/
├── logo.png
├── style.css
├── firebase-config.js
├── icons.js
├── password-rules.js
├── app-shell.js
└── *.html
```

## ⚠️ قبل الاستخدام
1. Firebase Console ← Authentication ← Settings ← Authorized domains ← أضف نطاق نشر هذا الموقع.
2. Firebase Console ← Realtime Database ← Rules ← الصق محتوى `firebase-rules.json` المرفق.

لا حاجة لتفعيل Firebase Storage: المرفقات (PDF/صور) أصبحت روابط خارجية عادية يضيفها المسؤول، مش رفع فعلي، فملف `storage-rules.txt` المرفق أصبح غير مطلوب (باقٍ للرجوع إليه فقط لو رجعتوا لنظام الرفع المباشر مستقبلًا).

## كورسات ومسابقات معًا

كل عنصر محتوى (كورس أو مسابقة) له نوع يحدده المسؤول عند الإضافة:
- **كورس** → زر "اشتراك في الكورس"
- **مسابقة** → زر "انضمام للمسابقة"

نفس بنية المحاضرات (فيديوهات + اختبارات + مرفقات) تنطبق على الاثنين، والفرق بينهم شكلي فقط (تسمية وأيقونة مختلفة) وليس تقنيًا.

## الاشتراك الحقيقي
زر الاشتراك موجود في أعلى صفحة `competition.html?id=...` (صفحة تفاصيل الكورس/المسابقة). المستخدم يقدر يتصفح تفاصيل المحتوى بحرية، لكن قائمة المحاضرات تفضل مقفولة تمامًا لحد ما يضغط الزر ويؤكد في نافذة التأكيد ("هل تريد تأكيد الاشتراك؟ نعم/لا"). بمجرد التأكيد يُسجَّل اشتراكه في قاعدة البيانات (`enrollments` و`userEnrollments`) وتنفتح المحاضرات فورًا حسب قواعد النشر والترتيب المعتادة. الوصول المباشر لروابط `video.html` أو `exam.html` بدون اشتراك مسبق يُرفض أيضًا.

## الجرس: إشعارات حقيقية
جرس في الهيدر بجانب النقاط، يعرض إشعارين فقط:
- إشعار لما المسؤول يرد على تعليقك على أي فيديو.
- إشعار لكل **المشتركين فعليًا** في كورس/مسابقة معيّن لما تُضاف محاضرة جديدة له (مفيش إشعار عام لكل المستخدمين عند إضافة كورس/مسابقة جديد بالكامل).

عداد أحمر يوضح عدد الإشعارات غير المقروءة، وتُعلَّم كمقروءة بمجرد الضغط عليها.

## نظام المستويات
صفحة الحساب الشخصي بتعرض بطاقة مستوى بناءً على إجمالي نقاطك:

| النقاط | المستوى |
|---|---|
| 0 - 99 | 🥉 برونزي |
| 100 - 299 | 🥈 فضي |
| 300 - 699 | 🏆 ذهبي |
| 700 - 1499 | 💎 بلاتيني |
| 1500+ | 👑 الماسي (أعلى مستوى) |

مع شريط تقدّم يوضح كام نقطة باقي للمستوى التالي.

## الكورسات/المسابقات المشترك بها
نفس الصفحة بتعرض كل كورس أو مسابقة اشترك/انضم فيها المستخدم، مع شريط نسبة الإنجاز (عدد المحاضرات المكتملة من الإجمالي).

## وصف طويل؟ "عرض المزيد"
لو وصف الكورس/المسابقة أطول من حد معين، تظهر نسخة مختصرة منه مع زر "عرض المزيد" يفتح الوصف الكامل في نافذة عائمة، بدل ما ياخد مساحة كبيرة في الصفحة.

## المرفقات (روابط PDF وصور)
لو المسؤول أضاف روابط PDF أو صور على محاضرة معيّنة، هتظهر في نفس قائمة المحاضرة (بجانب الفيديوهات والاختبارات) بأيقونة مميزة، وتفتح مباشرة في تبويب جديد عند الضغط. الملفات نفسها مستضافة على أي خدمة خارجية (Google Drive، Dropbox، إلخ) ويكتفي المسؤول بلصق رابطها — لا يوجد رفع مباشر من لوحة التحكم، وبالتالي لا حاجة لتفعيل Firebase Storage.

## حد المشاهدات وإحصائيات المحاضرة (video.html)
داخل صفحة الفيديو نفسها (بعد ما يدخل الطالب من قائمة المحاضرات)، بتظهر بطاقة تفاصيل فيها: وصف المحاضرة (نفس حقل `description` بتاع المحاضرة)، مدة الفيديو، عدد المشاهدات المستخدمة من الإجمالي المسموح، إجمالي وقت المشاهدة الفعلي، ونسبة أعلى نقطة وصلها الطالب في الفيديو.

- **عدد المشاهدات المسموح بها**: يضبطه المسؤول لكل فيديو على حدة بإضافة حقل `maxViews` (رقم) يدويًا على عنصر الفيديو في Firebase Console. لو الحقل مش موجود، الافتراضي 3 مشاهدات.
- **خصم مشاهدة**: بيتم تلقائيًا أول ما الطالب يوصل لـ80% من مدة الفيديو في نفس الجلسة (مرة واحدة بس لكل دخول للصفحة، حتى لو رجّع الفيديو لورا وقدّمه تاني)، ويتسجل في `userProgress/.../videos/{videoId}/viewsUsed`.
- **لما المشاهدات تخلص**: الطالب يقدر يفتح صفحة الفيديو ويشوف كل التفاصيل (الوصف، المدة، الإحصائيات) لكن الفيديو نفسه ما يشتغلش — بيظهر له بدل المشغل رسالة إنه استنفد مشاهداته.
- **مدة الفيديو**: لو المسؤول حدّدها يدويًا بحقل `durationMinutes` (رقم بالدقايق) على عنصر الفيديو، بتتعرض فورًا حتى لو الفيديو مقفول. لو مش محدّدة، بتتجاب تلقائيًا من مشغّل يوتيوب بعد ما يجهز (وبالتالي متعرفش تظهر لو الفيديو مقفول أصلًا).
- **إجمالي وقت المشاهدة**: بيتراكم فعليًا (ثانية بثانية أثناء التشغيل الفعلي فقط، مش وقت التوقف)، ويتحفظ دوريًا كل 4 ثواني وكمان لما الطالب يسيب الصفحة، في `userProgress/.../videos/{videoId}/totalWatchSeconds`.

## زر الدعم الفني العائم
زر دائري ثابت أسفل الشاشة في كل صفحات الموقع، مكتوب عليه "الدعم الفني"، رابطه فارغ حاليًا (`href="#"`) لحد ما تجهّز صفحة دعم فني مخصصة — حدّثه وقتها في `app-shell.js` بدالة `renderSupportFab()`.

## نسيت كلمة المرور
رابط "نسيت كلمة المرور؟" في صفحة الدخول يفتح نافذة تأكيد، وبعد الموافقة يرسل رابط إعادة تعيين حقيقي عبر Firebase لموقع `awab-reset-site` المستقل (راجع README الخاص بيه).

## زر المشاركة والتعليقات
- زر المشاركة في `video.html` يعمل فعليًا (مشاركة الجهاز → نسخ تلقائي → نسخ يدوي كحل أخير).
- التعليقات محفوظة وحقيقية، ظاهرة للجميع، والمسؤول بس يقدر يرد عليها (سجّل دخولك هنا بحساب `admin@awab.su.com` لو عاوز تجرب الرد).

## منتدى الأسئلة (لكل كورس/مسابقة)
زر "منتدى الأسئلة" موجود في صفحة `competition.html?id=...`، وبيودّي لصفحة `forum.html?id=...` مخصصة لكل كورس/مسابقة على حدة — لازم اشتراك فعلي فيه أولاً عشان تقدر تسأل أو تشوف الأسئلة (زي قفل المحاضرات بالظبط).

- أي مشترك يقدر يكتب سؤال (نص إلزامي + صورة اختيارية)، وبيظهر فورًا في الفيد بحالة "بانتظار رد الإدارة".
- الصورة المرفقة (لو موجودة) بتتضغط في المتصفح وتتحول Base64 وتتخزن مباشرة في قاعدة البيانات، لأن الموقع مش بيستخدم Firebase Storage (نفس فلسفة عدم الرفع المباشر المذكورة فوق).
- بمجرد ما يرسل السؤال، يظهر له تنبيه "لقد تم إرسال سؤالك، سوف يتم الرد عليه في أقرب وقت".
- المسؤول بس (`isAdmin: true`) هو اللي يقدر يرد على سؤال معيّن، ورده بيظهر تحت السؤال لكل الناس فورًا (استماع حي، زي نظام تعليقات الفيديو بالظبط). أي مستخدم عادي — حتى صاحب السؤال نفسه — مايقدرش يرد.
- بمجرد الرد، يوصل إشعار حقيقي لصاحب السؤال في جرس الإشعارات برابط مباشر للمنتدى.

## هيكل البيانات في قاعدة البيانات

```
users/{uid}
  name, email, points, isAdmin, blocked, createdAt, lastLoginAt

competitions/{compId}
  title, description, coverUrl, type ('course' | 'competition')
  lessons/{lessonId}
    title, releaseAt
    videos/{videoId}: { title, url, maxViews?, durationMinutes? }
      comments/{commentId}: { uid, name, text, createdAt, adminReply? }
    exams/{examId}: { title }
      questions/{qId}: { text, options[4], correct, points }
    materials/{materialId}: { name, url, type: 'pdf'|'image', createdAt }

enrollments/{compId}/{uid}: timestamp
userEnrollments/{uid}/{compId}: timestamp
  (نفس علاقة الاشتراك، مسجّلة في الاتجاهين لسهولة الاستعلام من الطرفين)

userProgress/{uid}/{compId}/{lessonId}
  completed, earnedPoints
  videos/{videoId}: { watched, viewsUsed, maxWatchedPercent, totalWatchSeconds }
  exams/{examId}: { completed, score, earnedPoints, answeredAt }

notifications/{uid}/{notifId}
  type ('reply' | 'lesson'), title, body, link, read, createdAt

forumQuestions/{compId}/{questionId}
  uid, name, text, imageData? (Base64 data URL مضغوطة، اختيارية), createdAt
  adminReply?: { text, createdAt }
```

## ⚠️ ملاحظة عن ملف storage-rules.txt
لم يعد الموقع يستخدم Firebase Storage؛ الملف مُبقًى فقط كمرجع سابق ولا حاجة للصقه في Firebase Console.
